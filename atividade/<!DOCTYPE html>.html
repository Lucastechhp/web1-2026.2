Exemplo de Fontes no CSS

Abaixo está o texto formatado utilizando as 5 propriedades fundamentais de fonte do CSS:

Este texto usa todas as propriedades de fonte!

Código CSS Aplicado:

p {
  font-family: Georgia, serif; /* Tipo da letra */
  font-size: 22px;             /* Tamanho */
  font-weight: 700;            /* Negrito/Espessura */
  font-style: italic;          /* Inclinação (Itálico) */
  font-variant: small-caps;    /* Maiúsculas Peq. */
}

Atalho Resumido (Shorthand):

Você também pode escrever todas elas juntas usando apenas a propriedade font na ordem correta:

p {
  /* [style] [variant] [weight] [size] [family] */
  font: italic small-caps 700 22px Georgia, serif;
}
